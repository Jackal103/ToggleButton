## Суть работы

При нажатии на кнопку под PIN_NUM(PIN_BUTTON)0 один раз светодиод загорается и при отпускании кнопки, не выключается. При следующем нажати кнопка выключает светодиод, при отпускании не переключает его обратно.

Т.е реализовна работа переключателя для кнопки на плате ESP32 

## Чуть глубже 

1) Разберем цикл while.
Внутри цикла 1ой строчкой написана функция для паузы, нужен только для защиты от дребезгов. При нажатии на кнопку контакты начинают дребезжать из-за этого могут быть ложные срабатывания. vTaskDelay нужен только для зажиты от них. 
  Так же если бы этой паузы небыло то цикл крутился бы млн/сек. из-за чего процессор платы загружался на 100% очень быстро.
2) Создана булевая переменная для опроса кнопки в данный момент времени. 
3) В операторе if стоит условие переключения самой кнопки. Мы хотим среагировать на то что кнопка только что перешла из состояния отпущена.
4) В строчке для установления режима светодиода я использую переменнюу led_state(gpio_set_level(PIN_LED, led_state)) и инвертирую каждый раз когда кнопку нажимают. Следоваительно светодиод включается, либо выключается, отталкмиваясь от режима в котором он работал в последнем состоянии.
5) После опреатором if происходит обновление даннх в переменной last_state присваивая себе прошлое сосотояние кнопки.
